# 🎯 Arrow Escape

A logic-based sliding puzzle game developed using **Flutter** and the **Flame Engine**. 
Shift the environment, plan your moves, and guide your arrow to the exit!

## 🌟 Key Features
* **Innovative Mechanics**: Control the player's movement by shifting the grid rows and columns.
* **Progressive Difficulty**: Hundreds of handcrafted levels across multiple chapters.
* **Cross-Platform**: Play seamlessly on Android, iOS, and Web.
* **Cloud Sync**: Log in with Google to save your progress and sync across devices.
* **Auto-Recovery**: Accidentally deleted your account? We restore it automatically if you return within 30 days!
* **Admin Dashboard**: View detailed statistics and level difficulties via a dedicated React-based web admin page.

## 🛠️ Tech Stack
* **Frontend**: Flutter (v3.2+), Flame Engine
* **Backend**: Firebase (Authentication, Firestore, Hosting)
* **Monetization**: Google AdMob (Rewarded & Interstitial Ads)
* **Admin Panel**: React, Vite, TailwindCSS

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/[YourUsername]/arrow-escape.git
   cd arrow-escape
   ```

2. **Install Dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the App**
   ```bash
   flutter run
   ```

## 🔒 Firebase Configuration
To run this project, you need your own Firebase configuration files, as security keys are not included in this repository.
* Android: Place your `google-services.json` in `android/app/`
* iOS: Place your `GoogleService-Info.plist` in `ios/Runner/`
